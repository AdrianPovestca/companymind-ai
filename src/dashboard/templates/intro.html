Email Agent

Autonomous system that reads Gmail, categorizes emails, and sends contextual replies.

THE WORKFLOW

Gmail → Fetch → Analyze → Decide → Reply → Sent

How It Works

1

Fetch Emails

Connect to Gmail via OAuth2. Read unread emails with full context - subject, sender, body, thread ID.

2

Analyze

Categorize email type (sales, support, billing, inquiry). Detect language. Assess urgency (low/medium/high).

3

Decide

Smart rules: urgent emails need human review. Simple inquiries get auto-reply. Complex issues escalate.

4

Generate Reply

Create contextual response in detected language. For English, Romanian, German, Russian. Professional tone.

5

Send

Send reply back via Gmail API. Mark as replied in database. Update dashboard stats in real-time.

6

Track

Log all decisions in SQLite. Track which emails were auto-replied, escalated, or sent for human review.

What It Does

Smart Categorization

Automatically classify: Sales inquiries, Support requests, Billing issues, General questions, Complaints.

Language Detection

Detect email language and reply in same language. Supports English, Romanian, German, Russian.

Urgency Assessment

Mark complaints and high-urgency emails for human review. Auto-reply to simple, low-risk emails.

Email Threading

Maintain conversation context. Track related emails in same thread. Understand conversation history.

Database Tracking

SQLite logs every email: content, decision, category, language, urgency. Full audit trail.

Live Dashboard

Real-time stats. See pending emails, auto-replied count, total processed. One-click processing.

Get Started

Prerequisites: Python 3.12+, Gmail account with OAuth credentials

# Install
pip install -r requirements.txt

# Configure
cp .env.example .env
# Add your Gmail OAuth credentials

# Run
python run_dashboard.py
# Visit http://localhost:5000
