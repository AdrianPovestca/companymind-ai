## 📋 HOW TO USE (For Customers)

1. Clone repo
2. `pip install -r requirements.txt`
3. Create `.env` with email provider credentials
4. `python -c "from src.agent_factory import create_email_agent; connector = create_email_agent()"`
5. Agent processes emails automatically
